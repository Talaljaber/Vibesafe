# @talaljaber/vibesafe-shared

Shared types, constants, severity weights and finding id helpers used by the VibeSafe packages ([`@talaljaber/vibesafe-core`](https://www.npmjs.com/package/@talaljaber/vibesafe-core), [`@talaljaber/vibesafe-cli`](https://www.npmjs.com/package/@talaljaber/vibesafe-cli) and [`@talaljaber/vibesafe-mcp`](https://www.npmjs.com/package/@talaljaber/vibesafe-mcp)). You normally do not install it directly.

Full documentation: [github.com/Talaljaber/Vibesafe](https://github.com/Talaljaber/Vibesafe#readme).
